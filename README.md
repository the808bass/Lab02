# Лабораторная работа №2: Классы, агрегация и композиция

**Тема:** Проектирование автоматизированной системы управления режимами переработки на мусоросжигательном заводе.
**Дисциплина:** Объектно-ориентированное программирование

## Описание проекта
В работе реализована модель управления мусоросжигательным заводом на языке C++. 
Продемонстрированы отношения между классами:
*   **Композиция:** Класс `Furnace` (Печь) владеет датчиками `Sensor`. Датчики хранятся в `std::vector` по значению и уничтожаются вместе с печью.
*   **Агрегация:** Класс `Batch` (Партия отходов) использует печь `Furnace` через указатель. Партия не владеет печью, и уничтожение партии не влияет на время жизни печи.

## Структура проекта
*   `sensor.hpp` / `sensor.cpp` — класс датчика (измеряет параметры).
*   `furnace.hpp` / `furnace.cpp` — класс печи (управляет режимом, содержит датчики).
*   `batch.hpp` / `batch.cpp` — класс партии отходов (ссылается на печь).
*   `main.cpp` — демонстрационная программа, показывающая работу связей, время жизни объектов и ручное управление памятью (`new`/`delete`).
*   `Lab02_OOP.sln` — файл решения для Visual Studio 2019.

## Как запустить проект
1. Установите **Visual Studio 2019** (или новее) с рабочей нагрузкой «Разработка классических приложений на C++».
2. Откройте файл решения `Lab02_OOP.sln`.
3. Нажмите **F5** (или выберите «Сборка» -> «Сборка решения», а затем «Отладка» -> «Начать отладку»).
4. В открывшемся окне консоли отобразится порядок вызова конструкторов и деструкторов, демонстрирующий разницу времени жизни при композиции и агрегации.
